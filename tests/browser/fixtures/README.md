`narrow.ttf` is the MIT-licensed test font from Justineo/vue-clamp, commit
`9f93dbcc31f60b02dc34fbd6a9da9bf90edc6d84`, at
`packages/vue-clamp/tests/fixtures/narrow.ttf`. The accompanying LICENSE is retained.

It contains a space and rectangular `i`, both with a 250-unit advance in a
1000-unit em. It makes delayed font replacement observable without depending
on fonts installed on the test machine.
